# Application

Open `app/index.html`.

## Workflow

1. Choose a bank PDF.
2. Enter its PDF password if required.
3. Analyze the statement.
4. Review the transaction ledger and data-quality confidence.
5. Use Overview, Monthly, Merchants and Tax / ITR sections.

The app keeps withdrawal and deposit amounts separate from payment mode. Loan and credit-card payments are separate categories and are excluded from genuine-consumption spending to avoid double counting.

Tax estimates use the current AY 2026-27 individual slab configuration in the application and should be reconciled against official tax records before filing.
